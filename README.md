
# Mini CV en ligne
Un site web personnel qui présente mon profil, mes compétences et mes projets avec un design animé et moderne.

Technologies utilisées
- HTML5
- CSS3 (animations, transitions)
- JavaScript (animations et interactions)

Installation
1. Clonez le repo : git clone https://github.com/RACH-ARM/Tiamiyou-Aremou.git
2. Ouvrez index.html dans votre navigateur

Fonctionnalités
- Présentation personnelle
- Photo de profil animée
- Sections avec animations modernes
